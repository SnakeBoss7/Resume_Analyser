# ResumeAI

A smart resume analyzer tool for freshers and recruiters.

The goal is to help job seekers get honest, AI-driven feedback on their resumes — things like ATS score, missing keywords, and overall structure. Recruiters can bulk upload resumes, compare candidates, and get visual reports. Think of it as a smarter resume scanner, built from scratch.

### Features
- Single & bulk resume upload
- ATS-style scoring and keyword analysis
- Candidate ranking and summary charts
- Secure user auth (JWT)

🛠️ Still working on fine-tuning the scoring engine and adding LLM-based suggestions for resume improvement.

**Tech Stack:** React, Node.js, Express, MongoDB, Multer, OpenAI (planned)

**Status:** Actively being built, core logic in place.
